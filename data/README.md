# Data

현재 데이터셋은 없으며 합성 자료를 작성하기 위한 설계만 있다. NOVA INK Studios와 작품은 가상이다.

## 예정 자료

- 작품 설정집: 인물, 관계, 시간 순서, 항목 ID와 버전.
- 회차 원고: 장면 ID가 있는 텍스트와 버전.
- 독자 반응: 합성 댓글, 중복 여부와 표본 정보.
- 평가 미션: 입력 자료 참조, 주입한 오류, 기대되는 검수 결과.
- 데이터 manifest: 데이터 버전, 파일 목록, 합성 여부, 개발용/평가용 분할.

개발용과 최종 평가용 자료를 분리하고 최종 정답을 에이전트 입력에 넣지 않는다. 오류가 없는 사례와 판단을 보류해야 하는 사례도 포함한다. 실제 데이터가 없는데 성능 수치를 표시하지 않는다.

미공개 원고, 실제 독자 개인정보, 대화 원문, API 키는 공개 저장소에 넣지 않는다. 로컬 private/, raw/, generated/는 .gitignore로 제외한다. 공개 가능한 평가 결과는 검토 후 docs/에 명시적으로 작성한다.

평가 기준: [평가 설계](../docs/04-evaluation.md).
